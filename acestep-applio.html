ACE-Step and Applio

The two apps that turn the morning's lyrics into a finished vocal in his own voice. ACE-Step installs on the Mac. Applio runs in a browser tab and never touches it. Every command, with a checkpoint after each one.

Needs Apple Silicon, 16 GB or better ACE-Step on the Mac, port 7860 Applio in the browser, Colab notebook Verified 17 Aug 2026

Three things to know before he types anything

The first one is good news, and it deletes a whole session from this guide.

Applio never gets installed on the Mac. Running it in the browser means there is no run-install.sh, no Python 3.10 to install alongside his 3.12, and no version clash to work around. It also means the same Colab session that trained his voice is the one that converts with it, so training and inference stop being two different places. The Mac is left with ACE-Step, Demucs, ffmpeg, and the upload.

Neither app does the other's job. ACE-Step writes the song and sings it in a voice that is not his. Applio takes that finished vocal and replaces the timbre with his. There is no "use my voice" setting in one and no "write me a song" setting in the other. The build is the handoff between them.

The browser link is temporary, and this catches everyone

A gradio.live address is a tunnel to a running session, not a website. Gradio quotes one week and frequently gives less, and the moment the Colab session stops the link is dead no matter how old it is. Every working session produces a new address. Bookmarking one is wasted effort: the notebook is the thing to bookmark.

One branch before he starts. On an Intel Mac, or 8 GB of memory, ACE-Step locally is not worth attempting: run the music step in Colab too and keep the Mac for the video and the upload. Session 0 of the Mac guide has the full table.

Part one: ACE-Step, on the Mac

1

Install uv

2 minutesScreen share

ACE-Step does not use pip or conda. It uses uv, which reads the project's lockfile and builds the whole environment itself. This is good news: it is one command and it does not ask him to understand virtual environments. 

$ curl -LsSf https://astral.sh/uv/install.sh | sh

Then quit Terminal completely with Command+Q and reopen it, the same way Homebrew needed in session 1 of the Mac guide. The installer adds uv to the path, and the path only takes effect in a new session.

Checkpoint

This prints a version number rather than "command not found":

$ uv --version
uv 0.x.x
2

Clone ACE-Step and build its environment

10 minutes, mostly downloadingScreen share 
$ cd ~
$ git clone https://github.com/ace-step/ACE-Step-1.5.git
$ cd ACE-Step-1.5
$ uv sync

uv sync is the step that takes a while. It resolves every dependency and downloads them into a local environment inside the folder. Nothing outside ~/ACE-Step-1.5 is touched, which also means deleting that folder is a clean uninstall.

Checkpoint

uv run acestep --help prints usage text instead of a traceback. A traceback here almost always means the wrong Python version, so check python3 --version reads 3.11 or 3.12.

3

First launch, and the long download

5 minutes of typing, then 20 to 40 of waitingHim, alone

The repository ships a launcher written for macOS. Use it rather than the generic instructions:

$ cd ~/ACE-Step-1.5
$ chmod +x start_gradio_ui_macos.sh
$ ./start_gradio_ui_macos.sh

It detects the environment, checks for updates, installs anything missing, and starts the web interface. The first run also downloads the model weights, which are between 4 and 9 GB depending on which size he chooses. That download happens once.

If he would rather skip the environment checks on later days, uv run acestep starts the same interface directly. Both open http://localhost:7860 in the browser. This one is a real local address, not a tunnel, so it does not expire.

Checkpoint

The page loads at http://localhost:7860 and shows a lyrics box and a tags or style box. Leave the Terminal window open: closing it stops the app.

4

Turn the morning's email into a track

5 minutes a songHim, alone

Two fields, straight from the Grok reply. The ===ESTILO=== block goes into the tags or style field, and the ===LETRA=== block goes into the lyrics field.

The [verse] and [chorus] tags stay in English even though the words are Spanish. That is what the model reads to build the song's shape, and it is the most common thing to lose in a copy and paste. If the structure comes out wrong, check those tags first.

Set the duration to match DURACIÓN OBJETIVO from the prompt. Three and a half minutes is 210 seconds. On an M2 Max a track that length renders in about a minute and a half.

On 16 GB, use the smaller 2B model. The 4B is better and wants the memory to match. He can change this later without reinstalling anything, so start small and hear the difference before deciding.

Save the result as cancion.wav in ~/gospel-song/. Keep the name simple: no spaces, no accents. Applio rejects awkward filenames later and it is easier never to create one.

Checkpoint

cancion.wav plays, a voice is singing his Spanish lyrics, and the length is roughly what he asked for. The voice will not be his yet. That is the next half.

Part two: Applio, in a browser tab

5

Open the notebook and start the session

5 minutes, then a few of waitingHim, alone, every session

Applio publishes two Colab notebooks. The one that produces the interface in the browser is the UI version: 

https://colab.research.google.com/github/iahispano/applio/blob/main/assets/Applio.ipynb

Bookmark that address, not the link it generates. Before running anything, set Runtime, Change runtime type, T4 GPU, the same as the training session. Then run the cells in order. The last one prints a gradio.live address. Open it.

The second notebook, Applio_NoUI, is the one their documentation recommends generally, because it is steadier for long training runs. It has no interface, so for this build the UI version is the right pick. Use NoUI only if a training run keeps dying.

Checkpoint

The Applio page loads in a browser tab, with the row of tabs across the top reading Inference, Training, TTS, Voice Blender, Realtime, Plugins, Download, and the rest.

6

Put his voice into the session

2 minutes, every sessionHim, alone

A fresh session starts with no voices in it. His trained model has to go in each time, and the quickest route is the Download tab, which has a Drop files section built for exactly this.

Drop the .pth there, then drop the .index. Applio reads the model name out of each filename, makes a folder for it, and files them together. It tidies the usual index prefixes on the way, so added_ and nprobe_1_ on the front of the index name do not stop the pair from grouping under one voice.

The same tab has a Model Link field that fetches a model from a URL. If he parks the two files somewhere with a direct link, that becomes a paste instead of two uploads. Worth doing once he is tired of dragging them.

Only .pth and .index are accepted

Dropping a zip, a folder, or anything else is refused outright with an error about an invalid model file. If Colab exported his training run as an archive, unzip it first and drop the two files inside.

Checkpoint

Back on the Inference tab, press Refresh. His model name now appears in the Voice Model dropdown, and the matching file appears under Index File.

7

The Inference tab, field by field

3 minutes a songHim, alone

Top to bottom, in the order the page is laid out:

Voice Model. His model, from session 6. Index File. Its matching index. If either dropdown is empty, press Refresh before assuming something broke.

Single or Batch. Single is right for one song a day. Batch takes a folder path and is worth knowing about only if he ever falls a week behind.

Upload Audio. Drag the vocal stem onto the drop area, or click it and browse. This is where the file leaves the Mac. Select Audio underneath then picks which uploaded file to convert.

I agree to the terms of use. A checkbox, and it gates the Convert button. It is the single most common reason a first attempt appears to do nothing at all.

Convert. Progress appears under Output Information, and Export Audio saves the result back down to the Mac.

The four Advanced Settings worth touching

SettingWhat it doesWhere to start
Pitch Shifts the output in semitones. Negative goes lower, positive goes higher. 0. Use 12 or -12 only if the song lands an octave off.
Index Rate How closely the output chases his recorded timbre rather than the input vocal. 0.3 to 0.8. Push it up for more of him, down when it turns metallic.
Protect Voiceless Consonants Preserves consonants and breath instead of smearing them into the vowel. 0.3 to 0.7. Raise it if the words get mushy.
Volume Envelope Blends the output's loudness with the original's, so it does not over-compress. Leave it until a song comes back flat and lifeless.
Checkpoint

The converted file plays back in his voice, singing the same notes as the input. If it is his timbre but the wrong tune, that is Pitch. If it is the right tune but metallic, that is Index Rate.

Part three: the chain, every morning

8

Five steps from lyrics to a finished vocal

about 15 minutes a songHim, alone

The browser hop adds an upload and a download that the all-local version did not have. Everything else is the same, and the two apps still run side by side: ACE-Step in one tab on localhost:7860, Applio in another on its gradio.live address.

One. ACE-Step writes the track. Save it as cancion.wav.

Two. Demucs pulls the vocal away from everything else, on the Mac:

$ cd ~/gospel-song
$ demucs --two-stems=vocals cancion.wav
# -> separated/htdemucs/cancion/{vocals.wav, no_vocals.wav}

Three. Upload vocals.wav to the Applio tab, tick the terms box, and press Convert.

Four. Export Audio, and put the download into ~/gospel-song/ as vocals_clonada.wav. Browsers land files in ~/Downloads by default, so this is a move, not a wish.

Five. ffmpeg puts his vocal back over the untouched instrumental:

$ ffmpeg -i separated/htdemucs/cancion/no_vocals.wav -i vocals_clonada.wav \
    -filter_complex "[1:a]volume=1.15[v];[0:a][v]amix=inputs=2:duration=longest" \
    -c:a pcm_s16le final.wav

The volume=1.15 lifts the vocal slightly above the backing. It is the one number worth adjusting by ear on the first few songs, and once it sounds right it stays right.

Checkpoint

final.wav is the whole song, the voice is recognisably his, and the instrumental is undamaged. This is the file the video step in the pipeline plan expects.

9

What the browser hop costs him later

Not yetReference only

run_dia.py, from prompt 2 on the Prompts page, drives programs rather than clicking buttons. ACE-Step is ready for that already: uv run acestep-api starts a REST server on http://localhost:8001, which is what the script will call.

Applio in a browser tab is the one part that cannot be automated as it stands, because the whole point of the share link is that it moves. When the day comes to script this properly, the voice step is the piece that has to come back onto the Mac. That is a fair trade for getting started now without an install, and it costs nothing until then, since the script is weeks away regardless.

When something goes wrong

The first three are specific to running Applio in a browser and account for most first-week frustration.

What he seesWhere it comes fromWhat to do
Convert does nothing at all Applio The terms of use box is not ticked. It gates the button and gives no warning.
The page will not load any more Gradio The share link expired or the session stopped. Reopen the notebook, run the cells, take the new address, and reload his model.
His voice is missing from the dropdown Applio Press Refresh first. If still absent, the files never landed: redo the Download tab drop.
An error mentioning the audio file Applio Spaces or accents in the filename. Rename to something plain before uploading.
Vocal sounds metallic or robotic Applio Lower the index rate. If it persists across every song, the dataset was speech rather than singing and needs rerecording.
Vocal is in the wrong octave Applio The pitch setting, in semitones. Twelve up or twelve down is one octave.
Song has no chorus, or repeats oddly ACE-Step The [verse] and [chorus] tags did not survive the paste. Check the lyrics box, not the model.
Backing instruments bleed into the converted vocal Demucs Separation was imperfect before Applio ever saw it. Try UVR with a different model for that song.
Track is much shorter or longer than asked ACE-Step The duration control, not the lyrics. Set it in seconds and regenerate.
